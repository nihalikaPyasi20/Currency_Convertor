# Currency Converter

A simple and responsive Currency Converter web application built using HTML, CSS, and JavaScript. It allows users to convert an amount from one currency to another using exchange-rate data fetched from an API.

## Features

- Convert between multiple currencies
- Select source and target currencies
- Dynamic country flags
- Fetch exchange rates using an API
- Displays the converted amount
- Simple and user-friendly interface

## Technologies & Tools Used

- HTML5 – Used to create the structure of the application
- CSS3 – Used for styling and layout
- JavaScript – Used for DOM manipulation, event handling, API fetching, and currency conversion logic
- Currency Exchange API – Used to fetch exchange-rate data
- Flags API – Used to display country flags
- Font Awesome – Used for icons
- VS Code – Used for development
- Git & GitHub – Used for version control and project hosting

## How to Use

1. Enter the amount you want to convert.
2. Select the currency you want to convert from.
3. Select the currency you want to convert to.
4. Click on **Get Exchange Rate**.
5. The converted amount will be displayed.
